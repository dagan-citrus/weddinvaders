# PART A — DETAILED DESIGN (implementer)

## A1. Decisions

| # | Decision | Why |
|---|----------|-----|
| RD1 | **Hand-rolled router, no new dependency.** A pure `matchRoute` plus about 40 lines of History API glue (`usePathname`, `navigate`, `Link`). | The route space is flat: nine fixed paths and one single-segment slug. The slug rule (case-insensitive registry lookup, reserved names, not-found) has to be our own pure function with either choice. `react-router@8` would force a React bump and add a large API for `Routes`/`Link`/`NavLink`; v7 means adopting a superseded major. Active-nav is `aria-current` from the same match; titles are a field in the route table. Swap-out path if nested routes or data loading ever appear: `Link`/`navigate`/`usePathname` keep their signatures. |
| RD2 | **Deep links: `dist/404.html` is a byte copy of `dist/index.html`**, written by a small Vite plugin in `vite.config.js`. No per-route HTML files in T4. | Smallest thing that satisfies G5. Per-route files need per-page metadata to be worth it and cannot list event slugs from Node (the registry imports PNGs); that belongs with T12. See risk K1. |
| RD3 | **One route table in `src/routes.js`, derived from `SITE_PAGE_SLUGS`.** `routes.js` has no JSX. | Nav (T5), reserved slugs (T2) and routing cannot drift: adding a page means adding it to `SITE_PAGE_SLUGS` and giving it a title. |
| RD4 | **Matching rules**: only the pathname is matched; query and hash are ignored and left in the URL. Empty segments are dropped, so trailing and doubled slashes are tolerated. Site pages and slugs both match case-insensitively. More than one segment is not-found. The URL is never rewritten (no canonical redirect). | `/Pricing` showing "Event not found" would be wrong, and `isReservedSlug` is already case-insensitive. |
| RD5 | **Event and demo pages render only `<Game>`**, with no site layout around it, exactly as `/` does today. Site pages and not-found render inside `SiteLayout`. | G7: the guest experience is unchanged. `SiteLayout` is the single plug point for T5. |
| RD6 | **Document title is set from the match** by one effect in `App`. `index.html` is untouched. | Minimal; T12 owns metadata. |
| RD7 | **Component-to-route mapping lives in `App.jsx`** (`PAGE_COMPONENTS`), defaulting to `PlaceholderPage`. | T5–T11 each replace one entry. |

## A4. Public API

### A4.1 `src/routes.js`

```js
/** @typedef {{ id: string, path: string|null, title: string }} RouteDef */
/** @typedef {{ route: RouteDef, event: EventConfig|null }} RouteMatch */

export const ROUTE_ID = Object.freeze({
  HOME: 'home', EVENT: 'event', NOT_FOUND: 'not-found',
  ...SITE_PAGE_SLUGS,            // DEMO: 'demo', … — a site route's id IS its slug
});
export const HOME_ROUTE      // { id: 'home',      path: '/',  title: SITE_CONFIG.name }
export const EVENT_ROUTE     // { id: 'event',     path: null, title: '' }
export const NOT_FOUND_ROUTE // { id: 'not-found', path: null, title: 'Event not found' }
export const SITE_ROUTES     // frozen RouteDef[8], in Object.values(SITE_PAGE_SLUGS) order;
                             // id = slug, path = '/' + slug, title from the table below
export const NAV_ROUTES      // frozen [HOME_ROUTE, ...SITE_ROUTES]
export function matchRoute(pathname, registry = eventRegistry)  // → RouteMatch, never throws
export function getDocumentTitle(match)                         // → string
```

Titles (also the placeholder headings and nav labels, except Home whose nav label is `Home`):

| slug | title |
|---|---|
| `demo` | `Demo` |
| `customize` | `Customize` |
| `pricing` | `Pricing` |
| `how-it-works` | `How it works` |
| `order` | `Order` |
| `showcase` | `Showcase` |
| `privacy` | `Privacy` |
| `terms` | `Terms` |

Building `SITE_ROUTES` must throw at module load if a slug in `SITE_PAGE_SLUGS` has no title.

`matchRoute(pathname, registry)` algorithm:
1. If `pathname` is not a string, or `decodeURIComponent` throws → `{ route: NOT_FOUND_ROUTE, event: null }`.
2. `segments = decoded.split('/').filter(Boolean)`.
3. 0 segments → `HOME_ROUTE`.
4. 2 or more segments → `NOT_FOUND_ROUTE`.
5. 1 segment: if `normalizeSlug(segment)` equals a `SITE_ROUTES` id → that route. Otherwise `registry.findBySlug(segment)`; found → `{ route: EVENT_ROUTE, event }`; else `NOT_FOUND_ROUTE`.

`event` is `null` for every route except `EVENT_ROUTE`. The returned `route` is the table object itself (stable identity). The caller passes a pathname only; a `?` or `#` in the argument is not stripped.

`getDocumentTitle(match)`:
- home → `SITE_CONFIG.name` (`Weddin'Vaders`)
- event → `` `${event.names.bride} & ${event.names.groom} | ${SITE_CONFIG.name}` `` (default: `Bride & Groom | Weddin'Vaders`)
- everything else → `` `${route.title} | ${SITE_CONFIG.name}` `` (e.g. `Pricing | Weddin'Vaders`, `Event not found | Weddin'Vaders`)

### A4.2 `src/navigation.js`

```js
export function usePathname()                           // → window.location.pathname, re-renders on change
export function navigate(to, { replace = false } = {})  // → void
```
- `usePathname`: `useSyncExternalStore(subscribe, () => window.location.pathname)`; `subscribe` adds and removes a `popstate` listener on `window`.
- `navigate`: `history.pushState(null, '', to)` (or `replaceState`), then `window.dispatchEvent(new PopStateEvent('popstate'))`. `to` is a same-origin path that may carry `?query#hash`. No scroll handling (K4).

### A4.3 `src/Link.jsx`

`export default function Link({ to, onClick, ...rest })` renders `<a href={to} {...rest}>`. On click: call `onClick` if given; then, only when `!event.defaultPrevented`, `event.button === 0`, none of meta/ctrl/shift/alt is held, and `rest.target` is unset or `'_self'`: `preventDefault()` and `navigate(to)`. Internal paths only.

### A4.4 `src/App.jsx`

```jsx
const PAGE_COMPONENTS = { [ROUTE_ID.HOME]: HomePage };   // T5–T11 add entries

export default function App() {
  const match = matchRoute(usePathname());
  const { route, event } = match;
  const title = getDocumentTitle(match);
  useEffect(() => { document.title = title; }, [title]);

  if (route.id === ROUTE_ID.EVENT) return <EventPage event={event} />;
  if (route.id === ROUTE_ID.DEMO)  return <DemoPage />;
  const Page = route.id === ROUTE_ID.NOT_FOUND ? NotFoundPage
             : PAGE_COMPONENTS[route.id] ?? PlaceholderPage;
  return <SiteLayout routeId={route.id}><Page route={route} /></SiteLayout>;
}
```
`App` takes no props. `App.jsx` no longer imports `defaultEvent` or `Game`.

## A6. `vite.config.js` plugin

```js
import { copyFile } from 'node:fs/promises'
import { join } from 'node:path'

// GitHub Pages serves 404.html for unknown paths; a copy of index.html lets the SPA route them.
function spaFallback() {
  return {
    name: 'spa-404-fallback',
    apply: 'build',
    async writeBundle({ dir }) {
      await copyFile(join(dir, 'index.html'), join(dir, '404.html'))
    },
  }
}
// plugins: [react(), spaFallback()]
```
