# PART A — DETAILED DESIGN (implementer)

## A1. Decisions

| # | Decision | Why |
|---|---|---|
| CD1 | **Five options: `names`, `photos`, `messages`, `items`, `levels`.** Theme, music, language and controls are listed in a separate "What stays the same" section, not as options. | The plan row names "theme" but the config has no such field. Omitting it invites the question in every order email; "on request" is a promise of engineering. A plain "fixed today" list is truthful and saves a round-trip (D1). |
| CD2 | **"Before" values are read from `defaultEvent` in the component; "after" values live in the content module.** | The before side cannot drift from the game. The content module keeps T5's rule of importing only `../format.js`. |
| CD3 | **`h1` is `route.title` (`Customize`)**; the pitch line is a paragraph under it. | Keeps the T4 A5 heading hook and T5 SD5 pattern. |
| CD4 | Content rule extension: example values may be **numbers** (item price, level money, duration) and **arrays of item ids**. | They are formatted by the same templates as the default values. |
| CD5 | Rows stack (before above after) below 720px and sit side by side from 720px. No `<table>`. | A three-column table leaves 80px per column at 320px. |

## A4. Component

`export default function CustomizePage({ route })`, imports `customize` from `'../content'`, `defaultEvent`, `getEventPath` from `'../events'`, `fillTemplate` from `'../content/format.js'`, `SITE_CONFIG`, `ROUTE_ID`, `Link`.

```
<section class="site-section customize-intro" data-section="intro"><div class="site-container">
  <h1>{route.title}</h1> <p class="customize-headline">{intro.headline}</p> <p>{intro.body}</p>
<section class="site-section" data-section="options"><div class="site-container customize-options">
  per option: <article class="site-card customize-option" data-option={id}>
    <h2>{title}</h2> <p>{body}</p>
    <div class="customize-example" data-example={id}> rows </div>
<section class="site-section" data-section="fixed"> <h2>{fixed.heading}</h2> <p>{fixed.body}</p>
  <ul class="customize-fixed"> <li class="site-card" data-fixed={id}><h3>{title}</h3><p>{body}</p></li> </ul>
  <p class="customize-fixed-note">{fixed.note}</p>
<section class="site-section" data-section="cta"> <h2>{cta.heading}</h2> <p>{cta.body}</p>
  <Link class="site-btn site-btn-primary" to={'/' + ROUTE_ID.DEMO}>{cta.primaryCta}</Link>
  <Link class="site-btn site-btn-secondary" to={'/' + ROUTE_ID.ORDER}>{cta.secondaryCta}</Link>
```

Row markup, identical for every option:
```
<div class="customize-row" data-field={fieldId}>
  <p class="customize-row-label">{field.label}</p>            // omitted for items
  <div class="customize-variant" data-variant="before"><span class="customize-caption">{pairLabels.before}</span> VALUE</div>
  <div class="customize-variant" data-variant="after"><span class="customize-caption">{pairLabels.after}</span> VALUE</div>
</div>
```

Row values per option (`host = new URL(SITE_CONFIG.baseUrl).host`):

| Option | Rows (`data-field`) | Before | After |
|---|---|---|---|
| `names` | `bride`, `groom` | `defaultEvent.names[id]` | `example[id]` |
| | `address` | `host + getEventPath(defaultEvent.slug)` | `host + getEventPath(example.slug)` |
| `photos` | `bride`, `groom`, `couple` | `<img src={defaultEvent.images[id]} alt={field.alt} loading="lazy">` | `<span class="customize-photo-slot">{slotText}</span>` |
| `messages` | one per `fields` entry | `defaultEvent.messages[id]` | `example[id]` |
| `items` | one per `examples` entry, `data-field` = its `id` | the `defaultEvent.items` entry with that id | the example |
| `levels` | `name`, `subtitle` | `level[id]` where `level = defaultEvent.levels.find(l => l.id === example.levelId)` | `example[id]` |
| | `required` | ids mapped to `` `${item.emoji} ${item.label}` `` from `defaultEvent.items`, joined with `, ` | same mapping on `example.required` |
| | `money` | `fillTemplate(moneyTemplate, { amount: level.money })` | same on `example.money` |
| | `gameDuration` | `fillTemplate(durationTemplate, { seconds: level.gameDuration })` | same on `example.gameDuration` |

An item value (both sides) is `<span data-part="emoji">`, `<span data-part="label">`, `<span data-part="price">{fillTemplate(priceTemplate, { price })}</span>`. An example whose default item or level is missing is skipped.

CSS: `.customize-row` is a one-column grid, two columns (`1fr 1fr`) for the variants from 720px with the label spanning both; `.customize-variant` has `min-width: 0`; images `max-width: 100%; max-height: 120px; width: auto`; `.customize-photo-slot` is a dashed `--wv-pink` box; the after variant has a `--wv-gold` left border; `.customize-caption` is `--wv-text-sm`, muted, `display: block`; `.customize-fixed` is one column, two from 720px.
