# PART A — DETAILED DESIGN (implementer)

## A1. Design decisions

| # | Decision | Why |
|---|----------|-----|
| DD1 | **Per-event:** `slug`, `public`, `names`, `images`, `messages`, `items`, `levels`. **Global engine (stays in `constants.js`):** canvas/row/player/bullet/item dimensions and speeds, `AMMO_ORDER`, `AMMO_META`, `AMMO_DAMAGE`, `ROW_ADVANCE_SPEEDUP`, `HOURGLASS_SLOW_SECONDS`, lives, spawn cadence, controls/instruction text, generic prompts ("Press any key…", "Level Complete!"), popup texts. | G6 lists exactly names, images, items, labels, levels, messages. Ammo and controls are game mechanics, not couple-specific. |
| DD2 | **No `theme` field.** The background colours (`BG_TOP/MID/BOT` in `renderer.js`) stay engine constants. | Nothing in T3–T6 needs it. T7 only describes theme; add an optional field when a task implements it. |
| DD3 | **Single source of truth for default data:** `defaultEvent.items` **is** `WEDDING_ITEMS` and `defaultEvent.levels` **is** `LEVELS` (same array references, imported, not copied). T3 moves the literals into the event module and deletes the old exports. | Zero duplication now, zero gameplay risk (G7), and T2 leaves the game untouched. |
| DD4 | **Messages and image imports are the only temporary second copies:** the five message literals are inline in `renderer.js` and the three PNG imports are in `useAssets.js`. `defaultEvent` declares them again; T3 deletes the originals. | T2 may not edit the game. Vite dedupes the PNG assets. |
| DD5 | **Images (D2):** each event module `import`s its image files; the config carries the resulting URL **strings** in `images.{bride,groom,couple}`. | Vite hashes and bundles them; `useAssets` already does `img.src = <string>`. Also works for `/public` paths or data URLs. |
| DD6 | **Slugs keep display case** (`DanAndShelly`); matching uses a normalised key (trim + lowercase). | G2; pretty URLs for QR codes. |
| DD7 | **Format vs. availability are separate.** `validateEvent` checks slug format only. Reserved and duplicate slugs are rejected by `createEventRegistry`. | Keeps `validateEvent` pure and independent of site routes and other events. |
| DD8 | **The default event is registered** under slug `DemoWedding`, `public: true`. `/demo` (T6) imports `defaultEvent` directly. | Gives T4 a real `/<slug>` to route and T11 one showcase entry. See open question Q1. |
| DD9 | **Validation returns issues; registry construction throws.** `validateEvent` returns an array (for forms/tools); `assertValidEvent` and `createEventRegistry` throw `EventConfigError`. | An invalid bundled config should fail tests/build loudly. |
| DD10 | **`public` is a required boolean.** | A typo in an optional flag would silently hide an event; every top-level field is required, so no unknown-key policing is needed. |
| DD11 | **Item shape = today's `WEDDING_ITEMS` schema, unchanged.** Engine rules keyed on item ids (`parent_bride`/`parent_groom`, `mine`) are T3's to generalise (appendix A8). | T2 must not alter gameplay data. |
| DD12 | **No freezing** of event objects or of `WEDDING_ITEMS`/`LEVELS`; configs are immutable by convention. `SITE_CONFIG`, `RESERVED_SLUGS` and the constant maps are `Object.freeze`d. | Simplicity; freezing the shared arrays is a T3 concern. |

## A4. Public API

Style: plain JS, named exports only, 2-space indent, single quotes, JSDoc on every export.

### A4.1 `src/siteConfig.js`

```js
export const PLACEHOLDER_CONTACT_EMAIL = 'contact@example.com';

export const SITE_CONFIG = Object.freeze({
  name:         "Weddin'Vaders",
  baseUrl:      'https://weddinvaders.barvazone.com',   // origin only, NO trailing slash
  contactEmail: PLACEHOLDER_CONTACT_EMAIL,
});

export function buildSiteUrl(path = '', baseUrl = SITE_CONFIG.baseUrl) // → string
```

`buildSiteUrl`: strip all trailing `/` from `baseUrl`, strip all leading `/` from `path`, return `` `${base}/${path}` ``. No encoding, no validation.

- `buildSiteUrl()` → `'https://weddinvaders.barvazone.com/'`
- `buildSiteUrl('pricing')` and `buildSiteUrl('/pricing')` → `'https://weddinvaders.barvazone.com/pricing'`
- `buildSiteUrl('/x', 'https://example.org/')` → `'https://example.org/x'`

There is no separate `domain` field; consumers derive it with `new URL(SITE_CONFIG.baseUrl).host`.

### A4.2 `src/events/slug.js`

```js
export const SLUG_MIN_LENGTH = 3;
export const SLUG_MAX_LENGTH = 40;

export function normalizeSlug(input)   // → string
export function isValidSlug(slug)      // → boolean

export const SITE_PAGE_SLUGS = Object.freeze({
  DEMO: 'demo', CUSTOMIZE: 'customize', PRICING: 'pricing', HOW_IT_WORKS: 'how-it-works',
  ORDER: 'order', SHOWCASE: 'showcase', PRIVACY: 'privacy', TERMS: 'terms',
});

export const RESERVED_SLUGS   // frozen string[]
export function isReservedSlug(slug)   // → boolean
```

- `normalizeSlug(input)`: if `typeof input !== 'string'` return `''`; else `input.trim().toLowerCase()` (not `toLocaleLowerCase`). It does not validate, strip slashes or URL-decode — T4 passes the bare path segment.
  - `'DanAndShelly'` → `'danandshelly'`; `'  Dan-And-Shelly '` → `'dan-and-shelly'`; `''`, `undefined`, `null`, `42` → `''`.
- `isValidSlug(slug)`: true iff `slug` is a string, `SLUG_MIN_LENGTH ≤ length ≤ SLUG_MAX_LENGTH`, and it matches `/^[A-Za-z0-9]+(?:-[A-Za-z0-9]+)*$/`. No trimming. It says nothing about reserved or taken.
  - Valid: `'DanAndShelly'`, `'dan-and-shelly'`, `'abc'`, `'2026Wedding'`, 40 × `'a'`.
  - Invalid: `'ab'`, 41 × `'a'`, `''`, `' Dan'`, `'Dan Shelly'`, `'dan_shelly'`, `'-dan'`, `'dan-'`, `'dan--shelly'`, `'dan/shelly'`, `'dan.shelly'`, `'דן-ושלי'`, `'café'`, `null`, `42`.
- `RESERVED_SLUGS`: frozen, all lowercase, no duplicates — `Object.values(SITE_PAGE_SLUGS)` followed by `'assets'` (Vite's output directory, a real path collision), `'index'`, `'404'`, `'home'`, `'about'`, `'contact'`, `'faq'`, `'packages'`, `'events'`, `'admin'`, `'api'`, `'help'`, `'legal'`. 21 entries.
- `isReservedSlug(slug)`: `RESERVED_SLUGS.includes(normalizeSlug(slug))`. `'Demo'`, `' PRICING '`, `'How-It-Works'` → true; `'DanAndShelly'`, `'demos'`, `undefined` → false.

### A4.3 `src/events/eventConfig.js`

```js
export const PLAYER_ROLES = Object.freeze(['bride', 'groom']);
export const ITEM_EFFECTS = Object.freeze(['income', 'discount', 'mine', 'time']);

export const EVENT_ISSUE = Object.freeze({
  MISSING:        'missing',
  INVALID_TYPE:   'invalid-type',
  EMPTY:          'empty',
  INVALID_SLUG:   'invalid-slug',
  INVALID_NUMBER: 'invalid-number',
  NOT_ALLOWED:    'not-allowed',
  DUPLICATE_ID:   'duplicate-id',
  UNKNOWN_ITEM:   'unknown-item',
  NO_MINE_ITEM:   'no-mine-item',
  RESERVED_SLUG:  'reserved-slug',    // emitted only by createEventRegistry
  DUPLICATE_SLUG: 'duplicate-slug',   // emitted only by createEventRegistry
});

/** @typedef {{ path: string, code: string, message: string }} EventIssue */

export class EventConfigError extends Error   // .name === 'EventConfigError', .issues: EventIssue[]
export function validateEvent(candidate)      // → EventIssue[]   (never throws)
export function assertValidEvent(candidate)   // → candidate, or throws EventConfigError
```

- `EventIssue.path`: dot/bracket path from the event root — `'slug'`, `'names.bride'`, `'items[2].price'`, `'levels[0].required[1]'`; `''` for the root.
- `EventIssue.message`: non-empty English sentence naming the constraint (and the offending value where short). Wording is not contractual; `path` and `code` are.
- `new EventConfigError(issues)`: `message` is `` `Invalid event config (${issues.length} issue${issues.length === 1 ? '' : 's'}): ` `` followed by each `` `${path || '(root)'}: ${message}` `` joined with `'; '`. `issues` is stored as given.
- `assertValidEvent`: `const issues = validateEvent(c); if (issues.length) throw new EventConfigError(issues); return c;`

### A4.4 `src/events/registry.js`

```js
export const SLUG_STATUS = Object.freeze({
  AVAILABLE: 'available', INVALID: 'invalid', RESERVED: 'reserved', TAKEN: 'taken',
});

export function createEventRegistry(events)   // → EventRegistry, or throws EventConfigError
```

`createEventRegistry(events)`:

- `events` not an array → throw `EventConfigError` with the single issue `{ path: 'events', code: 'invalid-type' }`.
- For each `events[i]`, in order:
  - Run `validateEvent`; re-path each issue as `` `events[${i}].${path}` `` (or `` `events[${i}]` `` when path is `''`).
  - If the slug is a valid format and reserved → `{ path: 'events[i].slug', code: 'reserved-slug' }`.
  - Else if its normalised slug equals that of an earlier event → `{ path: 'events[i].slug', code: 'duplicate-slug' }` on the later one.
- Any issues → throw one `EventConfigError` with all of them. `[]` is valid (empty registry).
- The input array is copied; later mutation of the caller's array does not affect the registry. Event objects are stored by reference.

Returned `EventRegistry` (plain object of closures, no class):

| Method | Behaviour |
|--------|-----------|
| `findBySlug(slug)` → `EventConfig \| null` | Looks up `normalizeSlug(slug)`. Unknown, empty, non-string → `null`. Never throws. |
| `getSlugStatus(slug)` → `SLUG_STATUS` value | With `t = typeof slug === 'string' ? slug.trim() : ''`: `!isValidSlug(t)` → `'invalid'`; else `isReservedSlug(t)` → `'reserved'`; else found → `'taken'`; else `'available'`. |
| `isSlugAvailable(slug)` → `boolean` | `getSlugStatus(slug) === SLUG_STATUS.AVAILABLE`. |
| `listEvents()` → `EventConfig[]` | New array each call, registration order. |
| `listPublicEvents()` → `EventConfig[]` | New array each call, registration order, only `public === true`. |

## A5. Config shape and validation rules

Typedefs to declare in `eventConfig.js`: `EventConfig`, `EventNames`, `EventImages`, `EventMessages`, `EventItem`, `EventLevel`, `EventIssue`.

### Rule vocabulary

- **Required**: `undefined` or `null` → `missing`.
- **String**: non-string → `invalid-type`; `value.trim() === ''` → `empty`.
- **Boolean**: non-boolean → `invalid-type` (no truthy coercion).
- **Number**: `typeof !== 'number'` → `invalid-type`; `NaN`, `±Infinity`, or a violated constraint → `invalid-number`.
- **Enum**: wrong value of any type → `not-allowed`.
- **Object**: must be a non-null, non-array object, else `invalid-type`.
- **Array**: `!Array.isArray` → `invalid-type`; empty where "non-empty" is stated → `empty`.
- **Nullable**: `undefined` and `null` are both valid and mean "none".

### Reporting rules (tests rely on these)

1. At most one issue per path; the first failing check in the order missing → invalid-type → empty / format / number / enum wins.
2. If a container (root, `names`, `images`, `messages`, `items`, `items[i]`, `levels`, `levels[i]`, `required`, `optional`) fails, report it only and skip its children.
3. All independent faults are collected; emission follows the field order of the tables below. Callers and tests must not depend on order.
4. Unknown extra keys are ignored at every level.
5. Root not an object → exactly `[{ path: '', code: 'invalid-type' }]`.

### `EventConfig` (all fields required)

| Field | Type | Rule |
|-------|------|------|
| `slug` | string | Required. Non-string → `invalid-type`; `!isValidSlug` (including `''`) → `invalid-slug`. Not trimmed. Reserved is not checked here. |
| `public` | boolean | Required boolean. `true` = may be listed in the showcase (T11). |
| `names` | object | `names.bride`, `names.groom`: required strings. |
| `images` | object | `images.bride`, `images.groom`, `images.couple`: required strings (URL as produced by a Vite asset import, a `/public` path, or a data URL). Content is not checked. |
| `messages` | object | `title`, `tagline`, `finalMeeting`, `gameComplete`, `lost`: required strings. |
| `items` | `EventItem[]` | Required non-empty array. |
| `levels` | `EventLevel[]` | Required non-empty array. |

`messages` meaning: `title` = big heading on the title screen; `tagline` = line under it; `finalMeeting` = headline in the meeting scene after the last level; `gameComplete` = headline on the game-complete overlay; `lost` = headline on the lost overlay.

### `EventItem` (path prefix `items[i]`; each element must be an object)

| Field | Type | Req. | Rule |
|-------|------|------|------|
| `id` | string | yes | Required string. Equal to the `id` of an earlier item → `duplicate-id` on the later one. |
| `emoji` | string | yes | Required string. |
| `label` | string | yes | Required string. |
| `price` | number | yes | Finite, `>= 0`. Base price before `level.priceScale`. |
| `essential` | boolean | yes | Required boolean. |
| `exclusiveTo` | `'bride' \| 'groom' \| null` | nullable | Otherwise must be in `PLAYER_ROLES`, else `not-allowed`. |
| `incomeType` | `'income' \| 'discount' \| 'mine' \| 'time' \| null` | nullable | Otherwise must be in `ITEM_EFFECTS`, else `not-allowed`. `null` = plain purchasable. |
| `ammoRequired` | `'cash' \| 'invite' \| 'heart' \| null` | nullable | Otherwise must be in `AMMO_ORDER` (from `../constants`), else `not-allowed`. |
| `incomeAmount` | number | conditional | If `incomeType === 'income'`: required (`missing`). When present: finite, `>= 0`. |
| `discountPct` | number | conditional | If `incomeType === 'discount'`: required (`missing`). When present: finite, `0 < x < 1`. (A value of 1 would make every later shot deal zero damage.) |
| `spawnWeight` | number | optional | When present: finite, `> 0`. The engine defaults to 1. |

### `EventLevel` (path prefix `levels[i]`; each element must be an object)

| Field | Type | Rule |
|-------|------|------|
| `id` | number | Required; must equal `i + 1` (1-based, sequential — the repo's documented rule; shown as `LEVEL ${id}`). Else `invalid-number`. |
| `name` | string | Required string. |
| `subtitle` | string | Required string. |
| `required` | string[] | Required non-empty array. Each element: non-string → `invalid-type` at `levels[i].required[j]`; not the `id` of any item → `unknown-item`. **Duplicates are allowed** (`renderer.js` `drawPanel` counts multi-instance requirements). |
| `optional` | string[] | Required array, may be empty. Same element rules as `required`. |
| `money` | number | Finite, `>= 0`, `money % 100 === 0`, else `invalid-number` (cash ammo costs $100 a shot). |
| `priceScale` | number | Finite, `> 0`. |
| `itemSpeed` | number | Finite, `> 0`. |
| `rowAdvance` | number | Finite, `> 0` (seconds). |
| `gameDuration` | number | Finite, `> 0` (seconds). |
| `invites` | number | Integer, `>= 0`. |
| `hearts` | number | Integer, `>= 0`. |
| `hasMines` | boolean | Required boolean. If `true` and no item has `incomeType === 'mine'` → `no-mine-item` at `levels[i].hasMines`. |

Cross-reference checks (`unknown-item`, `no-mine-item`) run only when `items` is a valid array. The known-id set is every string `id` of an object element of `items`.
