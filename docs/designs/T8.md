## A1. Decisions

| # | Decision | Why |
|---|---|---|
| PD1 | **A price is a bare number; the currency is the single field `pricing.currency`.** Display goes through one new helper, `formatPrice`. | D7: replacing prices is editing numbers; changing currency is one line. |
| PD2 | **`pricing.pricesArePlaceholder` drives everything "example":** the notice in the intro, an `Example price` tag on every price and an `Example terms` tag on the terms section. | PD5 | **Tiers nest by config area:** Basic = names, address, photos, messages; Custom = + items; Premium = + levels and balance. | Each feature is a field group of the config, so nothing sold needs new engineering. |
| PD6 | **Delivery and hosting numbers live in `pricing.termValues`** and are filled into `{token}` text; they are covered by the same flag. | They are as unconfirmed as the prices. |

## A4. APIs

### A4.1 `formatPrice(amount, currency, locale = 'en-US')`
Returns `new Intl.NumberFormat(locale, { style: 'currency', currency, minimumFractionDigits: d, maximumFractionDigits: d }).format(amount)` with `d = Number.isInteger(amount) ? 0 : 2`. `formatPrice(149, 'USD')` → `$149`; `formatPrice(149.5, 'USD')` → `$149.50`; `formatPrice(149, 'ILS')` → `₪149`.

### A4.2 `src/pages/orderLink.js`
```js
export const PACKAGE_QUERY_PARAM = 'package';
export function getOrderPath(packageId)   // → `/${ROUTE_ID.ORDER}?${PACKAGE_QUERY_PARAM}=${encodeURIComponent(packageId)}`; no argument → `/${ROUTE_ID.ORDER}`
```
